# BYDMate-CN v4.0.1-cn.1

首个中文本地化发行版,基于上游 [BYDMate v4.0.1](https://github.com/AndyShaman/BYDMate)(PolyForm Noncommercial 1.0.0)。

## 本版改动

### 推送通道
- 新增 **Bark / 企业微信 / 飞书 / 钉钉** 推送通道,与 Telegram 并列可选;规则报告、离线重发队列、自动化报告动作全部走所选通道
- 飞书/钉钉自定义机器人签名(加签安全设置)已支持;文件直传(备份 zip、日志)仍仅 Telegram——国内 IM 机器人 webhook 不收文件,其他通道发文字说明

### AI 连接
- 新增 **Claude(Anthropic Messages API)** 连接槽位,可作主/备连接
- 自定义连接预设扩充并国内优先:**智谱 GLM / DeepSeek / Kimi / 通义 Qwen**,另保留 Cloudflare、Vercel 等
- 联网搜索新增 **智谱 web_search**,提供方可选(智谱/Exa/OpenRouter/z.ai),按选择排序逐级回退
- 天气新增 **和风天气(QWeather)**,配置 API Key 后自动启用,未配置保持 Open-Meteo

### DM-i 混动(汉 DM-i 适配第一批)
- 车型识别新增 `persist.sys.energytype` 快路径:系统属性一次读出 EV/混动,不再依赖计数器两次确认
- 混动计数器快照间隔 10 分钟 → 3 分钟,提高行程油耗(升数)配对成功率

### 更新与分发
- 更新检查通道可选:**GitHub / Gitee / gh-proxy / ghproxy.net**,所选排首位、其余自动回退(APK 下载走镜像)
- 新增 tag 触发的正式发版流水线(本页 APK 即由其构建,release 签名)

## 已知限制

- 熄火报告(helper 守护进程投递)暂仅 Telegram 通道
- 混动行程电耗 kWh、电续航槽位在部分车型可能显示"—",待实车 dump 校准 fid 后完善
- 语音助手仍为俄语(未改动)

## 安装

debug 构建用户请先卸载或直接安装本 release 签名包(签名不同,需卸载后安装)。DiLink 5.0 需已开启 ADB,`adb install -r BYDMate-v4.0.1-cn.1.apk`。
